## Design decisions
- **Bug (Task 1):** `check_collision` compared only the vehicle's *left-edge grid column* with the frog's column, ignoring vehicle width. Right-moving vehicles overlapped the frog for ~23 frames before being detected. Fix uses `Rect.colliderect` on the same rects that are drawn.
- **Respawn:** the start row has no traffic, so respawning there is safe without invulnerability.
- **Score:** progress points only for rows not yet reached in the current attempt (no farming by hopping back and forth); score is kept across lives.
- **Timer:** driven by real frame time (`dt` from `clock.tick`, capped at 0.1 s), so it is 30 real seconds. "Attempt" = one life.
- **Win/Game Over:** world and timer freeze; only `R` does anything.
